# 接口与端口

**通过将端口封装成固定的interface可以简化代码，控制进出方向**

首先是**interface**
如果没有modport控制方向，interface本质只是电线。
相当于bundle
但是有了modport就可以控制相对于声明模块的进出
特殊的，如果要实例化使用了interface的子模块，应当优先声明接口

如果需要双向驱动则需要声明wire
反之logic就可以了，省事


以这个为例子，
```
interface AHB_if(input clk);
  logic HCLK,HWIRITE; 
  logic [1:0] HTRANS;
  logic [7:0] HWDATA,HRDATA;
  logic [20:0] HADDR;
  assign HCLK = clk;
  bit rst;

  modport AHB_BUS (input HRDATA,
  output HCLK,HWIRITE,HTRANS, HWDATA, HADDR
  );

  modport test_if(
  input HCLK,HWIRITE,HTRANS, HWDATA, HADDR
);
  
endinterface

```
